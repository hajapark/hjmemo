## 다음 목표

HJMemo를 로컬 컴퓨터 밖에서도 안전하게 사용할 수 있는 웹서비스로 배포한다.

## 1. 배포 방식 결정

- [ ] 배포 서비스 후보 비교
  - Render
  - Fly.io
  - Railway
  - VPS와 Kamal
- [ ] 예상 사용자 수와 월 예산 정하기
- [ ] 첫 배포 서비스 한 곳 선택하기
- [ ] Git 원격 저장소와 배포 서비스 연결 방식 확인하기

완료 조건: 사용할 배포 서비스와 예상 비용이 결정되어 있다.

## 2. 운영 데이터베이스 준비

- [ ] 운영용 PostgreSQL 생성
- [ ] `DATABASE_URL` 연결 방식 확인
- [ ] 운영 환경에서 마이그레이션 실행 방법 확인
- [ ] 개발 DB와 운영 DB가 분리되었는지 확인
- [ ] 데이터베이스 자동 백업 제공 여부 확인

완료 조건: 운영 Rails 앱이 PostgreSQL에 연결되고 마이그레이션을 실행할 수 있다.

## 3. 이미지 영구 저장소 연결

- [ ] Amazon S3와 Cloudflare R2 비교
- [ ] 사용할 객체 저장소와 리전 선택
- [ ] 버킷 생성
- [ ] Active Storage 운영 서비스 설정
- [ ] 접근 키를 환경 변수 또는 Rails credentials에 저장
- [ ] 이미지 업로드·표시·교체·삭제 확인
- [ ] 파일 형식, 개수, 용량 제한이 운영 환경에서도 적용되는지 확인

완료 조건: 서버를 다시 배포해도 기존 이미지가 유지된다.

## 4. 운영 보안 설정

- [ ] `RAILS_MASTER_KEY` 또는 필요한 Rails 비밀값 등록
- [ ] 비밀값이 Git에 포함되지 않았는지 확인
- [ ] 운영 환경에서 HTTPS 강제 적용 확인
- [ ] 운영 호스트와 허용 도메인 설정
- [ ] 세션 쿠키의 보안 설정 확인
- [ ] Brakeman, Bundler Audit, Importmap Audit 재실행

완료 조건: 비밀값이 코드와 분리되어 있고 HTTPS로만 서비스에 접근할 수 있다.

## 5. 도메인과 서비스 주소 설정

- [ ] 사용할 도메인 결정
- [ ] DNS를 배포 서비스에 연결
- [ ] SSL 인증서 발급 확인
- [ ] Rails 운영 URL 설정
- [ ] 잘못된 주소의 404 화면 확인
- [ ] 헬스 체크 `/up` 확인

완료 조건: 실제 도메인에서 HTTPS로 HJMemo에 접속할 수 있다.

## 6. 비밀번호 재설정 이메일

현재 로컬 MVP에서는 메일 서비스가 없어 비밀번호 재설정을 비활성화했다.

- [ ] Resend, Postmark, Amazon SES 중 하나 선택
- [ ] 발신 도메인 인증
- [ ] Action Mailer 운영 설정
- [ ] Devise의 `recoverable` 모듈 다시 활성화
- [ ] 비밀번호 재설정 화면과 링크 활성화
- [ ] 재설정 메일 발송과 토큰 만료 확인

완료 조건: 사용자가 이메일을 받아 비밀번호를 안전하게 변경할 수 있다.
